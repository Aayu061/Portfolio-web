## 4. Key Architectural Highlights

- **Zero Framework Overhead:** Built purely with Vanilla HTML, modern modular CSS, and vanilla ES6+ JavaScript. No React, Vue, or bulky runtimes.
- **Interactive System Architecture Engine:** Live SVG/Canvas data-flow diagram in the Hero simulating client-to-cloud request pipelines with physics-based nodes and packet pulses.
- **Developer Command Palette (`Cmd+K` / `Ctrl+K`):** Global HUD for instant navigation, project search, theme toggling, and developer inspector tools.
- **Deep-Dive Case Study Drawers:** Accessible slide-over panels featuring interactive architecture diagrams, engineering trade-off matrices, and live code snippet viewers for 4 primary projects (*Place Your Service*, *Extreme Sales & Services*, *AI Café*, *FormaSpace*).
- **Procedural Web Audio Micro-Soundscape:** Mathematical frequency synthesis for crisp tactile clicks (opt-in, 0 bytes bandwidth).
- **Dual Adaptive Themes:** Midnight Navy (`#161E2F`) dark studio theme and Warm White (`#FFF5F0`) editorial light theme.

## 5. Development Principles

1. **Think. Design. Engineer. Deliver.**
2. **Performance First:** 60fps animations, sub-1.5s LCP, and zero cumulative layout shift (CLS).
3. **Accessibility as a Requirement:** Full WCAG 2.1 AA keyboard navigability, focus trapping, and screen-reader support.
4. **Authenticity:** All showcased projects, milestones, and technologies reflect genuine engineering implementations.
